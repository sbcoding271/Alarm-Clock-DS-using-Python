# ⏰ Digital Alarm Clock using Python

A simple **Digital Alarm Clock** developed using Python to demonstrate the practical implementation of **Data Structures and basic programming concepts**.

The project allows users to set, display, search, delete, snooze, and manage alarms through a command-line interface.

---

## 📌 Project Overview

The Digital Alarm Clock is a console-based Python application where users can create and manage multiple alarms.

The main purpose of this project is to understand how **Data Structures** can be used in a real-world application.

The project uses a **List** to store alarm records and performs operations such as:

- Insertion of alarms
- Searching for an alarm
- Deletion of an alarm
- Traversal of stored alarms
- Updating alarm information

---

## 🎯 Objectives

- To implement Data Structures using Python.
- To understand the practical use of Python Lists.
- To perform insertion, searching, deletion, and traversal operations.
- To implement a real-world application using basic Data Structure concepts.
- To understand object-oriented programming using Python classes.
- To implement alarm and snooze functionality.

---

## ✨ Features

- ⏰ Set a new alarm
- 📋 Display all alarms
- 🔍 Search alarm using Alarm ID
- 🗑️ Delete an alarm
- 🔔 Ring alarm with Windows beep sound
- 😴 Snooze alarm for 5 minutes
- ✅ Alarm status management
- 🕐 Real-time clock monitoring
- 🚪 Exit application safely
- 🏷️ Add labels to alarms
